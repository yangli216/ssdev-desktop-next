# Go WebPlus → Rust/Tauri 能力差异审计

本表以 `/Users/yangl/GolandProjects/web-plus/src/app` 的当前 Go 源码为旧行为证据。目标不是机械复刻全部接口，而是保留业务能力并消除 HTTP、主进程原生加载、任意命令和客户端私钥等长期风险。

| Go WebPlus 能力 | Rust/Tauri 目标 | 当前状态 | 决策 |
| --- | --- | --- | --- |
| `/plugin/invoke` | `window.ssdevDesktop.invokePlugin` / 可选持久操作 ID → Tauri IPC → 有界 controller → 隔离宿主 | 完成实现 | 保留请求/响应语义，不保留内部 HTTP；最多 8 个在途请求，容量饱和不排队；非幂等调用可跨刷新/崩溃防同 ID 重放并明确报告未知状态 |
| `runMode=standard/sandbox` | 始终按插件和架构隔离，同 key 并发首调单航班启动 | 完成实现 | 删除不安全的主进程加载模式；避免同一厂商组件被并发重复初始化 |
| DLL / OCX / COM / EXE / BAT | x86/x64 独立宿主 | 完成实现 | 保留并强化超时、崩溃回收和输出上限 |
| `license.dat` RSA 私钥解密 | Ed25519 公钥验签与完整文件清单 | 完成实现 | 旧许可证不能作为新信任根 |
| `/plugin/install` 本地替换 | `.ssdev-plugin` 安全解包、原子切换、回滚 | 完成实现 | 下载和安装分层；客户端只安装已签名包 |
| 插件版本 | 签名覆盖的 `plugin.json` SemVer | 完成实现 | 同版本可修复、允许升级、默认拒绝降级 |
| `/plugin/reload` | 按插件维护锁、目标宿主停机、目标路由原子替换 | 完成实现 | 单插件安装不影响无关插件；显式完整重扫先验签并预检全部有效组件，成功后才使用全局维护替换路由，无需重启桌面端；部署自检精确识别同数量清单漂移但不自动加载人工目录变化 |
| `/plugin/installed`、`/plugin/local` | 本地控制台插件清单 | 完成实现 | 只向本地控制窗口暴露版本、架构、服务和隔离错误，不向业务来源泄露路径 |
| 应用商店下载 | HTTPS 签名索引 + 包摘要 + 原子安装 | 完成实现 | 本地控制台只提交插件 ID，不信任业务页提供的任意下载 URL |
| `/system/openUrl` | `openExternal(url)` / `openWindow(request)` | 完成实现 | 系统浏览器只允许 HTTP(S) 和显式来源；受控业务窗口支持有界尺寸、坐标和屏幕选择；Tauri 窗口天然为 app 模式，不接受任意浏览器可执行文件；禁用 `_blank` 自动绕过 |
| 用户可编辑业务 URL | 发布方签名来源/服务/方法策略 + 用户配置子集 | 完成实现 | 正式构建不允许本地配置自行扩大 DLL 桥接信任边界；新增插件方法不会隐式授权；HTTP 必须签名例外 |
| `/system/command` | 签名进程策略 | 完成实现 | 不提供运行时任意命令接口，也不按基名白名单匹配 |
| `/system` BIOS、主板、网卡等 | `getSystemInfo()` 最小设备声明 | 完成实现 | 只保留 OS 类别、CPU 架构、客户端版本和协议版本；用户名及硬件指纹不迁移 |
| `/heartbeat` | `bridge_status` / 进程健康探针 | 完成内部实现 | Tauri 页面无需网络心跳 |
| `/static/*` 插件 HTML | 业务系统或签名资源包 | 不迁移 | 不启动通用静态文件服务器 |
| `/ws/slave` | Windows 专用双向命名管道 + 长度前缀 IPC | 完成实现 | 随机管道名、仅本机、双方 PID 校验和 Health 握手；插件标准输出与协议分离，WebSocket 回显不保留 |
| 系统托盘、单实例 | Tauri tray + single-instance | 完成实现 | 保留 |
| `/sys.desktop.windowNum.dic` 远端窗口上限 | 客户端固定资源上限 | 完成实现 | 最多同时保留 16 个受控业务窗口；不允许业务服务动态扩大客户端 WebView 资源边界，创建失败与销毁都会归还名额 |
| `Ctrl+Shift+A` 区域截图 | 本地冻结遮罩 + 归一化框选 + Rust 裁剪 | 完成实现 | 业务页只收到用户确认后的 PNG，不获得显示器原图或通用截图权限 |
| 开机启动 | Tauri/OS 登录启动策略 | 完成实现 | 必须由本地用户或管理员显式启用；配置写入失败时恢复原系统状态 |
| 自更新 | Tauri 签名更新清单 | 完成实现 | 只允许本地控制台触发；生产构建强制注入 HTTPS 端点、公钥和私钥，默认仅升级不降级 |
| `dllWinTop` 轮询抢焦点 | 明确的插件窗口前台请求 | 待真实插件确认 | 不恢复 100ms 全局抢焦点轮询 |
| 普通 Chrome/Edge 直连 7711 | 独立、默认关闭的兼容适配器 | 证据门禁完成、适配器有条件待实现 | 使用业务静态资源 + 真实流程 HAR 审计；只有运行时依赖确认且调用方无法同步迁移时交付 |

## 下一阶段优先级

1. 提供业务前端构建产物和覆盖代表性关键流程的 HAR；用迁移审计报告确认本地 HTTP 运行时依赖，并同时核对业务是否仍依赖用户名、BIOS、主板、磁盘、内存或网卡字段。
2. 用迁移审计工具盘点旧配置、插件和快捷键，再生成生产签名策略输入；只有 HAR 确认外部浏览器依赖且调用方无法同步迁移时，才进入独立 HTTP 适配器设计。
3. 用真实插件黄金矩阵验证 `installRun`、OCX 注册、硬件驱动和插件窗口行为；这些不能由源码推断替代。
4. 在发布环境演练更新密钥轮换、分批发布、失败回滚与旧版本恢复。
